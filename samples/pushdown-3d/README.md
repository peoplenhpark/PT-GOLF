# 케이블 푸시다운 완성본

모바일 주소: https://peoplenhpark.github.io/PT-GOLF/?v=48#exercise/pt_pushdown

기존 samples/pushdown-3d/ 주소도 위 실제 운동 상세로 연결됩니다.

배치: 준비·팔 펴기 2컷 → 입체로 자세 보기 버튼 → 움직임·느낌 → 운동 중 핵심 → 잊지 말 것 → 공통 원칙 → 내 메모.
확대 안내와 3D 부제/소개 문구는 표시하지 않습니다. 2컷의 브라우저 핀치 확대는 유지합니다.

기존 seed의 pt_pushdown을 그대로 사용합니다. 핵심 체크 6개, 잊지 말 것 3개, 해당 공통 원칙 13개, focus와 spec, 원문 갱신일 2026-08-21을 보존했습니다.
하단 메모·즐겨찾기·개별 수정은 기존 ptgolf_overlay_v1 저장소를 사용합니다. 실제 사용자의 기기 데이터를 이동하거나 초기화하지 않습니다.

viewer.html: 클릭 후에만 불러오는 3D 전용 iframe. 접거나 상세를 벗어나면 iframe을 제거합니다. 동일 출처·동일 iframe에서 온 높이 메시지만 반영합니다.
드래그/한 손가락 회전, 휠/두 손가락 확대, 앞·옆·뒤, 재생·일시정지, 동작 슬라이더, 0.5배속을 지원합니다.
모델은 직접 만든 단순화한 3D 인체입니다. 이미지 스타일은 Fleek 공개 화면을 참고했습니다. Three.js 0.160.1의 MIT 라이선스 원문은 THREE-LICENSE.txt에 있습니다.

릴리스: seed v33 유지, 앱/SW 자산 v47. 3D 전용 페이지와 이미지/스크립트를 SW 프리캐시에 포함했습니다.
검증: 390px 모바일 화면, 원문 전체 대조, 과거 전체 객체 형태의 메모·즐겨찾기·추가 큐 보존, 메모 저장/새로고침, HTML 문자열 안전 표시, 3D 로드/회전/접기, iframe 높이, 이전 주소 연결, 다른 운동 상세 유지.


2026-09-12: 이 표준을 전체47개 운동으로 확장했다. 공통 구현·생성 자산·검증 방법은 [전체 운동 미디어 문서](../../docs/visuals/README.md)를 참고한다. 푸시다운의 전용 뷰어와 원문은 유지한다.
