# 케이블 푸시다운 — 2컷 + 회전형 3D 샘플

모바일 검토 주소: https://peoplenhpark.github.io/PT-GOLF/samples/pushdown-3d/

상단: 준비/팔 펴기 2컷과 기존 코칭 설명. 브라우저 기본 핀치 확대 지원.
하단: 입체로 자세 보기 버튼을 눌러 3D 실행. 드래그/한 손가락 회전, 휠/두 손가락 확대, 앞·옆·뒤 시점, 재생·일시정지, 동작 슬라이더, 0.5배속 지원.

위의 그림은 AI로 생성한 해부학 스타일 이미지이며, 아래 모델은 직접 만든 단순화한 입체 인체입니다. 삼두 강조와 다크 화면은 Fleek 공개 화면을 참고했습니다. 손잡이는 예시이며 중량·횟수·손잡이 종류·상체 각도는 다음 수업에서 확인합니다.

기존 운동 데이터나 메인 앱 연결을 변경하지 않는 독립 검토 페이지입니다. 메인 앱의 자산 버전(v46)과 seed(v33)는 유지합니다. 라이브러리와 이미지는 모두 같은 폴더의 상대경로로 제공됩니다. Three.js 0.160.1 MIT 라이선스 원문: THREE-LICENSE.txt.

검증: Chrome 드래그·휠, 재생·일시정지, 앞/뒤 시점, 모바일 390px 폭, 두 손가락 확대, 2컷 로드 및 3D 지연 실행. 브라우저 오류 없음.
