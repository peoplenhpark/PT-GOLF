# HT 중심 정리 · 2026-11-13

사용자 요청: PT 지금 할 것은 마지막 상체(11.06)·하체(11.13) 수업을 중심으로 통합하고 오래된 중복 안내를 정리한다. 이후 운동은 HT 중심으로 자료와 경로를 연결한다.

홈·하단 탐색의 운동 시작은 HT를 우선한다. PT 지금 할 것은 두 수업의 서로 다른 동작14개를 기본3·상체7·하체4로 한 번씩만 보여 주는 HT 기준이다. 오늘 루틴 링크 하나를 우선하고 개인운동 자료와 원본 근거는 접어 둔다. 과거 일반 복습 문구·개인운동22종목의 중복 펼침 안내는 제거한다.

HT의 기존 주4회·기본20분/운동일70분·상체7/하체6·중량/분량/휴식은 유지한다. 루틴 뒤에서 통합 코칭 근거를 펼칠 수 있고, 전체 운동 자료는 활성 PT54+HT8을 ID당 한 번 표시한다. 개인운동22와 부위별 선택, HT 검색에서 PT 코칭과 참고 영상도 찾을 수 있다. 모든 운동 상세에서 HT 루틴·전체 자료·마지막 PT 기준으로 돌아간다.

운동의 원래 part와 ID를 바꾸거나 자료를 복제하지 않는다. PT 원본 날짜별 수업·개인 메모·즐겨찾기·초안·숨긴 항목·운동 영상·이미지·3D·설정 미확인은 보존한다. 골프 자료의 분류와 레슨은 유지한다. 기존 PT 주소도 계속 열리며 HT에서 같은 운동 상세로 연결한다.

사용자가 새 버전 배포를 요청했다. 표시4.3→4.4, 자산237→238로 갱신해 검증 후 배포한다. 이전 버전의 오프라인 준비 종목과 개인 기록은 기존 내용 해시 캐시 전환으로 보존한다.
